# Day 01 — Database Fundamentals

## 01. Database

### Definition
A Database is an organized collection of data that allows data to be stored, managed, and retrieved easily.

### Details
- Database માં data systematically store થાય છે.
- Data ને easily access, update અને manage કરી શકાય છે.
- Example: Student data, Employee data, Product data વગેરે.

---

## 02. DBMS

### Definition
DBMS (Database Management System) is software used to create, store, manage, and retrieve data from a database.

### Details
- Database સાથે કામ કરવા માટે DBMS ઉપયોગ થાય છે.
- Data ને insert, update, delete અને retrieve કરી શકાય છે.
- Examples: MySQL, PostgreSQL, Oracle, SQL Server.

---

## 03. Types of Databases

### Definition
Databases can be classified into different types based on how data is stored and organized.

### Types
- Relational Database
- Non-Relational Database / NoSQL
- Hierarchical Database
- Network Database
- Object-Oriented Database

### Details
દરેક database type data ને અલગ structure અને method થી store અને manage કરે છે.

---

## 04. Relational Database

### Definition
A Relational Database stores data in tables consisting of rows and columns, and tables can be related to each other.

### Details
- Data tables માં store થાય છે.
- Table માં rows અને columns હોય છે.
- Tables વચ્ચે relationships બનાવી શકાય છે.
- Relational databases માં SQL નો ઉપયોગ થાય છે.
- Examples: MySQL, PostgreSQL, Oracle, SQL Server.

---

## 05. Non-Relational Database / NoSQL

### Definition
A Non-Relational Database stores data without using the traditional table-based relational structure.

### Details
- Data ને tables સિવાય અલગ structures માં store કરી શકાય છે.
- Flexible data structure માટે ઉપયોગી છે.
- Large અને changing data માટે ઉપયોગ થઈ શકે છે.
- Examples: MongoDB, Redis, Cassandra.

---

## 06. Database Structure

### Definition
Database Structure describes how data is organized and stored inside a database.

### Structure

Database
↓
Tables
↓
Rows + Columns
↓
Data

### Details
- Database માં એક અથવા વધુ tables હોઈ શકે છે.
- Table માં rows અને columns હોય છે.
- Row એક record દર્શાવે છે.
- Column એક specific type of data દર્શાવે છે.

---

## 07. Table

### Definition
A Table is a structure in a database used to store data in rows and columns.

### Details
- Column data નો પ્રકાર અથવા field દર્શાવે છે.
- Row એક complete record દર્શાવે છે.
- એક database માં multiple tables હોઈ શકે છે.
- Relational databases માં table મુખ્ય data storage structure છે.

---

## 08. CRUD Operations

### Definition
CRUD represents the four basic operations used to manage data in a database.

### CRUD

- **C — Create** → New data create કરવું
- **R — Read** → Existing data read/retrieve કરવું
- **U — Update** → Existing data બદલવું
- **D — Delete** → Data delete કરવું

### Details
CRUD operations database માં data ને basic રીતે manage કરવા માટે ઉપયોગ થાય છે.
