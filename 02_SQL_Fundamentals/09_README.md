# 02 — SQL

## 09. SQL

### Definition
SQL (Structured Query Language) is a standard language used to communicate with and manage data in relational databases.

### Details
- SQL નો ઉપયોગ database માં data સાથે કામ કરવા માટે થાય છે.
- Data retrieve, insert, update અને delete કરી શકાય છે.
- Database અને tables create અને manage કરી શકાય છે.
- SQL relational databases સાથે મુખ્યત્વે ઉપયોગ થાય છે.
