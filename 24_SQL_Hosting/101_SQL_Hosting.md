SQL Hosting એટલે SQL database ને server પર host કરવું જેથી application અથવા website internet/network દ્વારા database સાથે connect થઈ શકે.

### Common SQL Hosting Options

* Shared Hosting
* VPS Hosting
* Cloud Database
* Dedicated Server
* Managed Database

### Basic Connection Flow

```text
Application
    ↓
Internet / Network
    ↓
SQL Server
    ↓
Database
    ↓
Tables
```

### Example

```text
Website
   ↓
Backend
   ↓
MySQL Database
   ↓
students table
```

### Explanation

SQL Hosting માં database local computer પર રાખવાને બદલે remote server પર રાખવામાં આવે છે. Application database server સાથે connection કરીને data store અને retrieve કરે છે.
