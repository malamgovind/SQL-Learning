# 04 — SQL Command Types

## 18. DDL

### Definition

DDL (Data Definition Language) is used to define and modify the structure of database objects such as databases and tables.

### Details

* DDL database structure સાથે કામ કરે છે.
* Database અને table create, modify અને delete કરવા માટે ઉપયોગ થાય છે.
* Common DDL commands: `CREATE`, `ALTER`, `DROP`, `TRUNCATE`.

---

## 19. DQL

### Definition

DQL (Data Query Language) is used to retrieve data from a database.

### Details

* Database માંથી data મેળવવા માટે ઉપયોગ થાય છે.
* મુખ્ય DQL command `SELECT` છે.

---

## 20. DML

### Definition

DML (Data Manipulation Language) is used to insert, modify, and delete data stored in database tables.

### Details

* Table ના data સાથે કામ કરે છે.
* Common DML commands: `INSERT`, `UPDATE`, `DELETE`.

---

## 21. DCL

### Definition

DCL (Data Control Language) is used to control access and permissions on database objects.

### Details

* Database users ના permissions manage કરવા માટે ઉપયોગ થાય છે.
* Common DCL commands: `GRANT`, `REVOKE`.

---

## 22. TCL

### Definition

TCL (Transaction Control Language) is used to manage transactions in a database.

### Details

* Database transactions ને control કરવા માટે ઉપયોગ થાય છે.
* Common TCL commands: `COMMIT`, `ROLLBACK`, `SAVEPOINT`.
